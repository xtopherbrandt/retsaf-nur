# Commit Message Format

This project uses Conventional Commits (default — no prior commit history to detect a convention from; revisit once a real pattern emerges).

Format: `type(scope): subject` — types: feat, fix, chore, docs, refactor, test
Case: lowercase
Scopes: none established yet

Examples (illustrative, not yet from this project's history):
